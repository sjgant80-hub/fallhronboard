## For the end user

Onboard new employees through 7 structured steps that capture everything the UK requires before day one.

### Wizard steps

| Step | What it captures |
|---|---|
| Personal | Name, contact, NI number, DOB, emergency contact |
| Job | Title, department, start date, hours, salary, probation, reporting line |
| Right to Work | Immigration Act 2006 — doc type, ref, verification date, expiry |
| Starter | P45 or starter declaration A/B/C, student loan plan, postgraduate loan |
| Bank | Account name, sort code, account number, building society roll |
| Pension | Auto-enrolment eligibility, opt-out, contribution %, provider |
| Consent | GDPR Art.13, disciplinary, grievance, equality, H&S, S.1 statement, contract |

### Key rules

- **Immigration Act 2006**: RTW verification before start date, TBAK civil penalty per illegal worker
- **Pensions Act 2008**: auto-enrolment within 3 months for eligible jobholders (22+ earning TBAk+)
- **ERA 1996 s.1**: written statement of particulars on or before day one
- **HMRC starter checklist**: declarations A/B/C determine initial tax code
- **UK GDPR Art.13**: privacy notice at point of data collection
